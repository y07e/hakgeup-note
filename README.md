# 쫑아빠의 학급노트

> 교사를 위한 모바일 최적화 학급 관리 웹앱

[![GitHub Pages](https://img.shields.io/badge/Demo-GitHub%20Pages-blue)](https://y07e.github.io/hakgeup-note/)

## 소개

**학급노트**는 초·중·고 담임교사가 학급을 효율적으로 관리할 수 있도록 만든 웹 앱입니다.
별도 설치 없이 브라우저에서 바로 사용할 수 있으며, 모든 데이터는 기기의 `localStorage`에 저장되어 **개인정보가 외부로 전송되지 않습니다.**

### 주요 특징

- **설치 불필요** — 브라우저 접속만으로 바로 사용
- **모바일 최적화** — 스마트폰에서 터치로 빠르게 조작
- **오프라인 지원** — 인터넷 없이도 사용 가능 (최초 로딩 후)
- **데이터 보호** — 모든 데이터는 기기 내 저장, 서버 전송 없음
- **단일 파일** — `index.html` 하나로 전체 앱 구동

## 주요 기능

### 1. 📝 출결 및 메모

| 기능 | 설명 |
|------|------|
| 학생 선택 | 번호 그리드에서 탭하여 학생 선택/해제 |
| 출결 기록 | 병결, 인정결석, 무단결석, 지각, 조퇴, 결과 등 |
| 메모 작성 | 자유 메모와 카테고리 태그 동시 기록 |
| 상벌점 | 상점/벌점 부여 및 사유 기록 |
| 날짜 선택 | 상단 날짜 선택으로 과거/미래 날짜 기록 가능 |

### 2. 🪑 자리배치

| 기능 | 설명 |
|------|------|
| 격자 설정 | 행(rows) × 열(cols) 자유 조절 (최대 8×7) |
| 드래그 배치 | 빈 칸 탭 → 학생 선택으로 배치 |
| 자리 이동 | 배치된 학생 탭 → 이동/교환 |
| 교탁 표시 | 격자 상단에 교탁 위치 표시 |
| 인쇄 | 자리배치표 인쇄 지원 |

### 3. 🧹 청소관리

| 기능 | 설명 |
|------|------|
| 기본 구역 | 교실 바닥, 창문/사물함, 복도, 화장실, 계단, 특별구역 |
| 구역 관리 | 구역 추가/삭제/이름 수정 |
| 인원 배정 | 구역별 학생 배정 및 해제 |
| 청소 메모 | 구역별 특이사항 메모 |
| 인쇄 | 청소구역표 인쇄 지원 (가로 방향) |

### 4. 📊 통계

| 기능 | 설명 |
|------|------|
| 대시보드 | 출석률, 총 상점/벌점, 이벤트 수 한눈에 확인 |
| 기간 검색 | 오늘 / 이번 주 / 이번 달 / 전체 / 사용자 지정 기간 |
| 카테고리 분석 | 카테고리별 메모 빈도 통계 |
| 학생별 조회 | 학생 선택 시 개별 기록 상세 확인 |
| 기록 삭제 | 개별 메모/상벌점 기록 삭제 |

### 5. ⚙ 기본 설정

| 기능 | 설명 |
|------|------|
| 학급 정보 | 학교명, 담임교사, 학년반 설정 |
| 학교 로고 | 로고 이미지 업로드 (헤더에 표시) |
| 학생 관리 | 학생 추가/삭제/이름 수정/공번 처리 |

| CSV 내보내기 | 전체 데이터 CSV 백업 |
| JSON 백업 | JSON 형태로 전체 데이터 백업/복원 |
| PIN 잠금 | 4자리 PIN 설정으로 앱 접근 보호 |
| 기록 초기화 | 메모/상벌점 데이터 전체 초기화 |

## 시작하기

### 최초 설정

1. 앱 접속 후 우측 상단 **⚙ 기본 설정** 버튼 클릭
2. **학교명**, **담임교사**, **학년반** 입력
3. (선택) 학교 로고 이미지 업로드
4. **학생 명단 등록**
   - 한 명씩 이름 입력하여 추가
   - 또는 CSV 파일로 일괄 등록
5. 설정 닫고 사용 시작

### CSV 학생 명단 형식

```
번호,이름
1,홍길동
2,김철수
3,이영희
```

## 배포 방법

### GitHub Pages 배포

1. **GitHub 저장소 생성**
   ```
   저장소 이름: hakgeup-note (또는 원하는 이름)
   공개(Public) 설정
   ```

2. **파일 업로드**
   ```bash
   git init
   git add index.html a2z-bold.ttf
   git commit -m "학급노트 앱 배포"
   git remote add origin https://github.com/[사용자명]/[저장소명].git
   git branch -M main
   git push -u origin main
   ```

3. **GitHub Pages 활성화**
   - 저장소 → Settings → Pages
   - Source: **Deploy from a branch**
   - Branch: **main** / **/ (root)**
   - Save 클릭

4. **배포 확인**
   - 1~2분 후 `https://[사용자명].github.io/[저장소명]/` 접속

### 직접 호스팅

`index.html`과 `a2z-bold.ttf` 파일을 아무 웹 서버에 올려도 동작합니다.

## 데이터 관리

### 저장 방식

모든 데이터는 브라우저의 `localStorage`에 저장됩니다.

| 키 | 내용 |
|----|------|
| `hn_ci` | 학급 정보 (학교명, 담임, 학년반, 로고) |
| `hn_st` | 학생 명단 |
| `hn_me` | 메모 기록 |
| `hn_pt` | 상벌점 기록 |
| `hn_se` | 자리배치 데이터 |
| `hn_cl` | 청소구역 데이터 |
| `hn_pin` | PIN 잠금 설정 |

### 백업 및 복원

- **설정 → JSON 내보내기**: 전체 데이터를 JSON 파일로 다운로드
- **설정 → JSON 가져오기**: 백업 파일에서 데이터 복원
- **설정 → CSV 내보내기**: 학생별 기록을 CSV로 내보내기

> 브라우저 데이터를 삭제하면 기록이 사라지므로 **정기적인 백업을 권장**합니다.

## 주의 사항

- 브라우저의 "사이트 데이터 삭제" 또는 "캐시 삭제" 시 데이터가 삭제될 수 있습니다.
- 시크릿/프라이빗 모드에서는 데이터가 저장되지 않습니다.
- 서로 다른 기기 간 데이터 동기화는 지원하지 않습니다 (JSON 백업/복원으로 이전 가능).
